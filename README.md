# Le Bac à sable

Parcours en autonomie pour aider les lycéens à comprendre et apprivoiser leur stress, avec des lectures, des vidéos et de petites activités.

- `index.html` : le parcours complet, en un seul fichier.
- `questionnaire/creer-formulaire.gs` : script qui crée le questionnaire d'avis dans Google Forms.

Le questionnaire d'avis est déjà relié au parcours (`FORM_URL` dans `index.html`).

Prototype pédagogique : il ne pose pas de diagnostic et ne remplace pas un professionnel de santé.
